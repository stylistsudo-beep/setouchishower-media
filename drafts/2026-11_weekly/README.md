## 確認できなかった理由（クラウド側）
- Instagramはログインしないと投稿が見えない。

- 非公開APIをブラウザを装って呼ぶ方法は、規約違反なので使わない。

## キャプションの文体ルール（須藤さんの指摘から）
- 正式な日本語。漢字表記をそろえる（挟まれた・囲まれた・足元）。
- 擬人化しない（×「タオルが待っている」）。
- 造語や古い言い方を避ける（×「湯の間」「あかりがともる」）。
- 設備名を並べるだけにしない。写真に写っている事実だけを書く。
- 「左」「右」は、読む人にとって曖昧なので使わない。

### 方針との食い違い
p22〜p44には、年末まで（p43「今年最後の、夕陽」、p44「今年も、ありがとうございました」）の投稿が並んでいる。
「月4回（金曜20:00）に減らす」方針と、この並びが合っていない。
- p22〜p44のうち、どれが投稿済みで、どれが予約・自動投稿の待ちかを確認する。
- 月4回にするなら、p22〜p44から4本/月を選び直すほうが、039・052・074を足すより先。
